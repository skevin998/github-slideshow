# 待确认问题

当前没有阻塞“我的客户”高保真交互 HTML 生成的问题。以下事项尚未形成全局规则，仅在相关需求出现时确认：

1. 除删除外，关闭、开启、变更主体或批量操作是否需要二次确认、审批、填写原因或审计日志。
2. 敏感字段是否需要脱敏及具体脱敏方式；当前版本不主动设计权限控制。
3. Drawer 存在未保存修改时，关闭是否必须确认；未另行说明时采用“有修改则确认”。

已确认的视觉参数统一由 [foundations.md](foundations.md) 管理；交互规则由 [patterns.md](patterns.md) 管理；页面与业务流程由 [my-customers-pages.md](my-customers-pages.md) 管理。本文件不得复制已确认规则。
