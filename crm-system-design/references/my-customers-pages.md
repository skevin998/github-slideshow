# “我的客户”页面与业务流程

本文件是页面层级、字段结构、打开方式和返回目标的唯一规则源。视觉参数使用 [基础规范](foundations.md)，通用交互使用 [组件与交互模式](patterns.md)。

## 页面地图

```text
集团客户
└── 我的客户（列表页/模块首页）
    └── 客户详情（新浏览器标签）
        ├── 基础信息
        ├── 公司列表
        │   ├── 按总公司查看
        │   │   └── 某总公司的分公司列表（当前标签下钻）
        │   ├── 全部公司明细
        │   ├── 客户—总公司—分公司图谱
        │   ├── 公司详情（当前标签下钻）
        │   │   ├── 关联分公司列表（仅总公司）
        │   │   └── 关联门店与终端列表（从支付业务进入）
        │   ├── 创建/批量创建公司
        │   └── 新增/编辑公司（Drawer）
        ├── 品牌列表
        │   ├── 卡片/列表切换
        │   └── 新增/编辑品牌（Drawer）
        ├── 产品管理
        ├── 批量操作记录
        └── 批量设置（当前标签下钻，Steps）
```

| 层级 | 页面 | 打开方式 | 返回 |
|---|---|---|---|
| L1 | 我的客户列表 | 侧栏入口 | 无模块内返回 |
| L2 | 客户详情 | 列表行“详情”打开新浏览器标签 | 关闭标签，原列表保持状态 |
| L2 内部 | 五个客户详情 Tabs | 当前详情页切换 | 不产生新标签 |
| L3 | 总公司分公司列表 | “按总公司查看”点击总公司，在当前标签下钻 | 返回按总公司查看及原状态 |
| L3 | 公司详情 | 公司列表、图谱或分公司列表点击主体，在当前标签下钻 | 返回实际来源视图及原状态 |
| L4 | 关联分公司列表 | 总公司详情基础资料的关联入口下钻 | 返回该总公司详情基础资料 |
| L4 | 关联门店页 | 支付业务中的商户门店入口下钻 | 返回该公司支付业务 Tab |
| L3 | 批量设置 | 从相关详情 Tab 在当前标签下钻 | 返回发起流程的 Tab 及原状态 |
| 浮层 | 新增、编辑、快速查看 | 右侧 Drawer | 关闭后停留来源页 |

同一客户重复打开时聚焦已有浏览器标签。公司详情、批量设置不得新开标签；新增和编辑不得变成独立页面或 Modal。

## A. 我的客户列表

对应 `列表页1.png`。

页面顺序：

1. 共享应用壳层。
2. 面包屑：`主页 / 我的客户`。
3. 客户与销售筛选、查询和重置。
4. 客户表格与分页。

筛选字段：

- 客户：支持客户名称或客户编号。
- 销售：支持销售名称。

表格列固定为：客户名称、客户编号、销售、创建时间、操作。“详情”为蓝色行内链接，打开客户详情。分页和筛选行为使用交互模式中的统一规则。

## B. 客户详情

对应 `详情页面1.1.png` 至 `详情页面1.5.png`。详情由客户摘要和业务内容两个白色一级模块组成。

客户摘要包含：`我的客户详情`、客户名称、`集团客户`类型标签、客户编号和复制操作。

客户详情 Tabs 顺序固定：

1. 基础信息
2. 公司列表
3. 品牌列表
4. 产品管理
5. 批量操作记录

这五个 Tabs 是客户详情内部导航，不是浏览器标签，也不写入 URL。

### B1. 基础信息

对应 `详情页面1.1.png`。

使用只读信息网格：

- 首行：客户名称、客户编号、销售人员。
- 次行：销售组织、创建时间。

缺失字段显示 `-`；不得使用禁用表单伪装只读详情。

### B2. 公司列表

对应 `详情页面1.2.png`。

- 工具栏左侧：创建公司、批量创建公司。
- 一级 Tab 内提供三个互斥视角：按总公司查看、全部公司明细、图谱。使用按钮式单选分段控件，不产生新页面或 URL 状态。
- 三个视角分别使用公司建筑、明细表格、关系图谱线性图标，置于文字左侧，随选中状态同色变化。
- 按总公司查看和全部公司明细显示公司关键词、公司类型、查询、重置；图谱不显示搜索区。
- 查询区独立位于创建操作与视角切换的下一行，起始位置与“创建公司”按钮左边缘对齐；所有支持的桌面宽度保持此布局。
- 公司和公司类型控件等分查询行的剩余空间，查询／重置操作组始终位于该行最右侧。创建操作和视角切换放在独立固定高度的一行中，图谱隐藏查询区时不改变该行的位置和对齐。
- 创建和编辑打开 Drawer；批量创建或设置进入下钻流程。

#### B2.1 按总公司查看

- 以总公司为分组维度展示汇总表。
- 底部使用通用交互规范中的统一分页器，统计当前筛选结果中的总公司数量；各视角分别保留页码和每页条数。
- 表格列固定为：总公司、公司编号、统一社会信用代码、分公司数量、操作。
- 点击任意行或“查看分公司”进入该总公司的分公司列表页。

#### B2.2 全部公司明细

- 平铺并分页展示全部公司主体，不分组、不展开收起；排列顺序为客户下的总公司，随后紧邻其分公司。
- 表格列固定为：公司主体、公司编号、统一社会信用代码、类型、上级公司、税号（电子发票）、支付业务、备注、操作。
- 分公司行使用缩进和层级图标区分；类型使用 Tag。
- 公司主体名称必须完整展示，长名称自动换行，不截断、不省略、不限制行数；行高随内容增加，层级图标与首行对齐。总公司汇总、分公司明细及关联分公司列表沿用此规则。
- 税号（电子发票）和支付业务使用含文字的“已开通 / 未开通”状态标签。
- 底部使用通用交互规范中的统一分页器，统计当前筛选结果中的公司主体数量。
- 筛选无结果时显示“未找到匹配的公司主体”并提供清除筛选。
- 点击任意行或“详情”进入公司详情，默认打开基础资料 Tab。

#### B2.3 图谱

- 以当前客户为根节点，以总公司为一级分支、分公司为二级分支，表达主体归属关系。
- 图谱采用从左到右的三级树状布局：客户根节点在左，总公司在中，所属分公司在右纵向排列，通过折线连接；图谱区域独立横向、纵向滚动。
- 总公司节点包含建筑图标、完整公司名称、总公司标签、法人、信用代码和分公司数量；数量按钮切换本组分公司的展开／收起。点击公司信息区域进入详情，不能与展开操作混用。
- 分公司节点包含完整名称、分公司标签、法人和信用代码，并提供向右进入详情的标识；类型视觉引用基础规范中的公司类型映射。
- 切换视角保持页面操作栏在当前视口的位置，各视角可单独保存内容区滚动位置；图谱下钻返回后恢复展开状态与图谱滚动位置。
- 图谱不显示搜索区；节点名称与类型始终可识别，不能只用颜色表达层级。
- 点击总公司或分公司节点进入对应公司详情，默认打开基础资料 Tab。

### B3. 品牌列表

对应 `详情页面1.3.png` 和 `新建页面.png`。

- 工具栏左侧：创建品牌、卡片/列表展示切换。
- 工具栏右侧：品牌名称、品牌编号、查询、重置。
- 展示切换使用 Ant Design v4 `Radio.Group` 按钮样式或等价行为。
- 卡片模式宽屏每行默认 3 张；展示 Logo、品牌名称、品牌编号、补充说明、创建日期和“详情”。
- 缺少 Logo 或说明时保持卡片结构稳定。
- 创建和编辑品牌打开右侧 Drawer。

### B4. 产品管理

对应 `详情页面1.4.png`。

- 使用两列产品能力卡片。
- 卡片包含产品名称、开通状态和说明。
- 已开通产品不重复显示开通操作；未开通产品提供“开通”主操作。
- 开通后的确认、审批和配置流程按具体产品需求确定，不从其他部门模块推导。

### B5. 批量操作记录

对应 `详情页面1.5.png`。

- 筛选字段：任务类型、状态、查询、重置。
- 表格列至少包括：创建时间、任务类型、操作人、状态、总行数、通过/不通过、执行结果、操作。
- 执行结果同时显示成功和失败数量；“查看详情”为行内链接。
- 状态视觉使用基础规范中的语义 Token。

## C. 某总公司的分公司列表下钻

- 从“按总公司查看”点击总公司进入，并在返回区提供返回总公司列表的入口。
- 顶部总公司信息卡包含名称、总公司 Tag、统一社会信用代码，以及“分公司 N · 联营开票 N”行内统计；统计样式遵循基础规范。联营开票数量使用独立业务字段，不以电子发票开通数量替代；原型使用模拟值，未提供时显示“-”，零值显示“0”。右侧操作组依次为“查看总公司详情”（默认按钮）和“添加分公司”（主按钮）。
- “查看总公司详情”在当前标签下钻进入该总公司详情，默认打开基础资料；返回后恢复当前分公司列表的分页和滚动位置。
- 分公司明细列与“全部公司明细”一致，但移除“上级公司”列。
- 点击分公司行进入公司详情；添加分公司打开新增公司 Drawer，并预设当前总公司为上级公司。

## D. 公司详情下钻

对应 `详情页面2.1.png`。

- 从公司列表、图谱或分公司列表在当前客户详情标签内进入，默认打开基础资料 Tab。
- 保留面包屑，并在其下方显示独立浅灰返回区。
- 返回实际来源视图，并恢复其筛选、视角、分页和滚动位置。
- 所有公司详情 Tab 共用主体信息头：主体图标、公司名称、统一社会信用代码、法人、类型与所属客户；右侧显示营业执照认证状态和由业务线汇总得到的业务总体状态。
- 公司详情二级 Tabs 固定为：基础资料、支付业务、电子发票；不得与客户详情五个 Tabs 合并。
- “编辑”打开右侧编辑 Drawer。

### D1. 基础资料

- 展示公司主体、公司编号、统一社会信用代码、类型、法人、上级公司、创建时间和备注。移除概览 Tab，业务内容分别保留在支付业务和电子发票 Tab 中。
- 底部提供关联公司入口：分公司显示“关联总公司 + 总公司名称”，点击直接进入总公司详情；总公司显示“关联分公司 · 共 N 家”，点击进入关联分公司列表。

### D2. 关联分公司列表

- 只从总公司详情基础资料进入，展示该总公司下辖的全部分公司。
- 表格列与分公司明细一致，不包含上级公司列；点击行进入对应分公司详情。
- 分公司详情中的“关联总公司”必须直接进入总公司详情，不经过本列表页。

### D3. 关联门店页

- 从支付业务 Tab 内某收钱吧商户的门店入口进入。
- 展示该商户关联的门店与终端清单，至少包含门店号、品牌、城市、终端 SN、型号、状态。
- 本 Skill 仅约束其页面层级、进入和返回关系；字段细节和业务规则以支付业务文档为准。

## E. 新增与编辑 Drawer

对应 `抽屉页面.png`、`新建页面.png`。

- 从右侧打开并保留背景上下文；顶部标题、关闭入口和底部操作区固定，内容区独立滚动。
- 表单采用顶部标签的纵向布局，必填字段显示红色星号。
- 编辑态不可修改字段可禁用，但内容仍应清晰；纯只读信息优先使用文本。
- 创建品牌可包含品牌名称、经营国家/地区、所属行业、标准 Logo 和横版 Logo。
- 上传区必须显示格式、大小和比例要求。
- 提交、关闭和成功后的上下文行为使用交互模式中的 Drawer 规则。

## F. 批量设置下钻流程

对应 `批量设置页面.png`。

- 在当前客户详情标签内进入，保留面包屑和独立浅灰返回区。
- 页面摘要显示任务名称、当前客户名称和编号。
- 流程固定为：上传文件 → 检查文件 → 执行导入。
- 上传阶段包含模板下载、格式/大小说明、拖拽上传区和“开始检查”；有效文件上传前按钮禁用。
- 截图示例使用 xlsx 且最大 5 MB；只在相同批量任务中沿用，其他任务按实际需求定义。
- 检查阶段展示总行数、通过数、不通过数和错误明细，并明确是否允许仅导入通过项。
- 执行阶段覆盖进行中、全部成功、部分失败和全部失败；完成后写入批量操作记录。
- 返回时恢复发起流程的 Tab 及其上下文。

## 禁止事项

- 不引入其他部门模块的业务规则。
- 不用客户详情覆盖原列表页。
- 不为公司详情或批量设置新开标签。
- 不把新增、编辑实现为独立页面或 Modal。
- 不把客户详情五个 Tabs 与公司详情内部 Tabs 合并。
