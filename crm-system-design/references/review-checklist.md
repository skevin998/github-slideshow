# 设计评审检查清单

本清单只用于确认规则已执行，不重复保存参数。视觉以 [基础规范](foundations.md) 为准，交互以 [组件与交互模式](patterns.md) 为准，页面流程以 [页面规范](my-customers-pages.md) 为准，HTML 验证以 [交付规范](html-delivery.md) 为准。

## 范围与层级

- [ ] 当前任务属于“集团客户 → 我的客户”或其直接子页面，没有引入其他部门规则。
- [ ] 页面层级、字段、打开方式和返回目标与页面规范一致。
- [ ] 客户详情五个 Tabs、公司详情下钻、批量设置下钻和 Drawer 层级没有混用。
- [ ] 公司列表三个视角属于同一 Tab；图谱没有搜索区，各下级页返回实际来源。
- [ ] 主操作明确，模块职责单一，没有无意义嵌套。

## 视觉基础

- [ ] 所有布局、尺寸、间距、颜色、排版、圆角和分辨率均来自基础规范，没有在其他文件或页面新增冲突值。
- [ ] 标准 Logo 使用 Skill 资产，没有重绘、改色、变形或叠加。
- [ ] 页面保持高密度桌面端产品语言，关键内容在全部支持视口可见或可达。
- [ ] Tabs、Select、表格、白色模块和返回区符合对应 Token。
- [ ] 状态同时使用文字和语义样式，图标风格一致。

## 交互与业务流程

- [ ] 查询只由明确操作触发，重置清空全部条件。
- [ ] Tabs 切换、详情往返和 Drawer 操作能保留规定的上下文。
- [ ] 公司视角切换、总公司分公司列表、关联公司和关联门店的跳转链路完整。
- [ ] 页面刷新后恢复初始状态，没有跨刷新持久化。
- [ ] 分页和当前页批量选择符合交互模式，不存在跨页全选。
- [ ] 新增、编辑和快速查看使用 Drawer；删除执行二次确认。
- [ ] loading、空状态、局部错误、成功、失败和恢复路径完整。
- [ ] 当前方案没有擅自增加权限、审批、脱敏或其他未确认规则。

## 组件与内容

- [ ] 组件选择符合 Ant Design v4 映射，没有使用 v5 专属能力。
- [ ] 表格列、信息字段、卡片内容、状态词汇和按钮文案与页面规范一致。
- [ ] 公司详情共用页头、四个二级 Tabs、业务卡和关联公司入口按主体类型正确变化。
- [ ] 长内容、空值、横向溢出、禁用原因和键盘焦点均得到处理。
- [ ] 图标按钮有可读名称，非通用操作不只显示图标。

## HTML 交付

- [ ] 只有一个 UTF-8 HTML，所有资源内联，断网可直接打开。
- [ ] 本次范围内的核心流程可操作，不是静态摆设。
- [ ] HTML 已在全部支持视口实际验证，且无控制台错误。
- [ ] 已走通主路径、取消、校验失败、提交失败和返回恢复。
- [ ] 未实现业务未显示为可点击，交付说明明确模拟数据和待确认事项。
